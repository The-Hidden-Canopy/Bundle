# Security policy

BUNDLE handles financial data. Please do not publish credentials, account
numbers, transaction exports, provider tokens, or other sensitive material in
a public issue or pull request.

For a suspected vulnerability, contact the repository maintainers through the
private security-reporting channel provided by the hosting repository. Include
the affected version or commit, a minimal reproduction using synthetic data,
the impact, and any proposed mitigation. Do not exploit or access another
person's financial data while investigating.

The core is intentionally local-first. A report that would require a cloud
service, mandatory telemetry, or provider credentials to reproduce should say
so explicitly; those are not ordinary core prerequisites.
